# AI 运动动作示意图生成 Prompt

## 功能介绍

这套 Prompt 用于将具体运动动作整理为中文手绘教学插画，适合居家锻炼记录、健身动作示意、运动教学图、小红书运动打卡和个人运动动作图库。

输入动作名称、连续动作步骤、步骤说明和需要强调的动作提示，可按需补充训练次数。提示词要求图片包含：

- 中文动作标题，以及用户提供的训练次数；
- 同一人物的三个连续动作阶段；
- 表示动作方向的箭头；
- 步骤编号、简短中文标签和注意事项。

这是**图片生成提示词，不是运动处方**。文中的次数仅演示标题排版，不代表推荐训练量；提示词也不能保证 AI 生成的动作符合专业教学标准。用于运动教学前，应人工核对动作结构与说明，不能仅凭画面美观判断动作正确性。

## 输入参数说明

| 参数 | 是否必填 | 作用与填写方式 |
| --- | --- | --- |
| 动作名称 | 必填 | 指定需要绘制的动作，例如“背后水瓶传递”；次数另填 |
| 训练次数 | 可选 | 例如“20次”；未提供时不显示，也不自动建议次数 |
| 动作步骤 | 必填 | 描述三个连续阶段的身体姿态、手脚位置及器械位置 |
| 步骤说明 | 必填 | 每个阶段对应的简短中文标签，例如“上手持瓶” |
| 动作提示 | 可选 | 提供需要强调的安全与动作要点；未提供时不显示底部提示 |
| 图片比例 | 可选 | 默认使用 3:4 竖版；如有其他用途，可统一修改模板中的比例要求 |
| 风格 | 可选 | 默认使用彩铅手绘教学插画；如需调整，应同步修改模板中的风格要求 |

将下面模板中的 `【……】` 替换为实际内容。训练次数、动作提示未提供时填写“未提供”；图片比例和风格已有默认值，可直接保留。动作步骤用于指导绘画，步骤说明才是图片中展示的短标签，避免把长段描述全部挤进画面。

## 通用 Prompt 模板

复制整个代码块，填写动作信息后交给支持图片生成的工具。以下使用自然语言描述画面，不依赖特定平台参数。

```text
请生成一张高质量的中文健身动作教学插画。

主题：【动作名称】
训练次数：【训练次数；未提供则填写“未提供”】
动作提示：【动作提示；未提供则填写“未提供”】
图片比例：3:4 竖版

画面要求：

1. 整体采用细腻、清晰的彩铅手绘插画风格。
2. 使用白色或浅米色纸张质感背景。
3. 画面干净简洁，适合运动教学和小红书图文记录。
4. 展示同一位成年女性完成该动作的三个连续阶段，按编号排列。
5. 人物穿着简洁运动服，人物外观、发型和服装在各步骤中保持一致。
6. 根据动作特点选择正面、侧面或背面视角，确保关键关节、器械位置和动作路径清晰可见；三个阶段保持相同观察视角。
7. 使用柔和蓝色箭头表示实际运动方向，箭头应对应移动的身体部位或器械，不遮挡关键关节。静态保持阶段不添加表示身体移动的箭头。
8. 每个步骤下方添加圆形编号①②③和对应的简短中文说明；完整动作描述仅用于指导绘画，不全部写入图片。
9. 在顶部添加清晰醒目的中文标题，标题内容为动作名称。
10. 如果提供训练次数，将次数直接标注在动作名称后面，用一个空格连接，例如“背后水瓶传递 20次”；标题作为完整的一行，次数不单独放到其他位置。未提供次数时只显示动作名称，不擅自生成建议次数，也不显示“未提供”或占位符。
11. 底部添加用户提供的动作提示；未提供时省略，不自行编造提示，也不显示“未提供”或占位符。
12. 保持人体比例合理、四肢数量正确、关节姿态自然，不为展示交接而强行扭曲肢体。
13. 器械位置应符合动作过程，避免器械漂浮、手指错误、动作前后不连贯；无需器械的动作不添加器械。
14. 图片中文字准确、清晰，避免错别字、乱码和重叠，不添加未要求的说明文字。
15. 输出上述比例的图片，默认是适合小红书图文记录的 3:4 竖版。三个阶段可横向排列；如果拥挤，改为纵向排列或上二下一的 2+1 布局，明确阅读顺序，优先保证动作清晰度。

步骤信息：

① 动作描述：【步骤一的身体姿态、手脚位置与器械位置】
   中文标签：【步骤一说明】
② 动作描述：【步骤二的身体姿态、手脚位置与器械位置】
   中文标签：【步骤二说明】
③ 动作描述：【步骤三的身体姿态、手脚位置与器械位置】
   中文标签：【步骤三说明】

风格要求：

- 彩铅手绘
- 柔和自然配色
- 清晰的教学结构
- 中文标题与步骤说明
- 简洁留白
- 不使用复杂背景
- 不使用照片写实风
- 不使用过度夸张的漫画风
- 不添加与动作无关的装饰
```

## 带次数的使用方式

将动作名称与训练次数分别填写：

```text
动作名称：背后水瓶传递
训练次数：20次
```

图片顶部的标题应完整呈现为：**背后水瓶传递 20次**。

“20次”应紧跟动作名称，不要单独放在角落、底部或步骤旁，也不要在其他位置重复标注。未提供次数时，标题只显示“背后水瓶传递”。不要让模型自行补充次数、组数或训练时长。

## 完整示例：背后水瓶传递

下面的 Prompt 已填写人物、步骤、标题和提示，可直接复制使用。这是动作示意，读者应根据自身活动能力调整动作幅度；“20次”仅为排版示例。

```text
请生成一张高质量的中文健身动作教学插画，主题为“背后水瓶传递”。

图片比例：3:4 竖版。
绘画风格：细腻、清晰的彩铅手绘，柔和自然配色。
背景：白色或浅米色纸张质感，画面简洁留白，不使用复杂背景、照片写实风、过度夸张的漫画风或无关装饰。

顶部标题必须逐字写为：
背后水瓶传递 20次

将标题放在同一行，“20次”紧跟动作名称，不单独放到其他位置，也不重复标注。不要添加其他次数、组数或训练时长。

人物与观察视角：

- 同一位成年女性背对观察者，穿浅紫色短袖和深色运动裤，扎丸子头。
- 三个阶段保持相同的人物外观、发型、服装、身体比例和背面观察视角。
- 采用能看清肩部、双臂、双手与水瓶的构图，双手和水瓶不得被裁切或文字遮挡。
- 每个阶段仅有一个水瓶，保持水瓶的外观和大小一致。
- 本组三个阶段中，右手始终是从肩上伸向背后的上方手，左手始终是从腰部下方伸向背后的下方手，不在中途交换左右手。

展示三个连续阶段：

① 上手持瓶
右手从肩膀上方伸向背后，握住水瓶；左手从腰部下方向背后伸出，准备接瓶。

② 背后交接
右手与左手在背后靠近。左手接触并握住同一个水瓶，右手在确认交接前仍扶住水瓶；两只手与水瓶的位置应连续、清晰。

③ 下手接住
左手接住并握稳水瓶，右手松开并离开；水瓶随下方的左手移动，不漂浮，不出现在另一只手中。

排版与方向：

- 在每个阶段下方添加圆形编号①②③，并分别写“上手持瓶”“背后交接”“下手接住”。
- 上述长段动作描述仅用于指导绘画，不全部写入图片。
- 用柔和蓝色箭头表示两只手的移动方向，箭头靠近对应手臂，不遮挡双手和交接处。上方手的箭头在交接前指向交接处，松开后指向离开方向；下方手的箭头表示接近水瓶的方向。
- 三个阶段按①②③排列。横向排列拥挤时，改用纵向排列或上二下一的 2+1 布局，保持编号顺序明确。
- 保持人体比例合理、四肢数量正确、手指和关节姿态自然；不要为让双手相接而强行扭曲肩膀或拉长手臂。
- 图片中的中文应准确、清晰，无错别字、乱码或重叠。

底部提示必须写为：
左右换手，缓慢完成；以舒适范围为准。

底部提示表示完成本组示意后可左右换手，不要在这三个连续阶段中改变上下手的身份。
```

## 其他动作示例

下面的信息可替换进通用模板，不需要重复复制整套画面要求。动作提示用于说明图中需要表达的要点，不替代个体化运动指导。

| 动作名称 | 三个关键步骤（可作为中文标签） | 推荐观察视角 | 简短动作提示 |
| --- | --- | --- | --- |
| 开合跳 | ① 并脚站立、双臂垂下 → ② 双脚向两侧跳开、双臂上举 → ③ 双脚跳回并拢、双臂放下 | 正面，完整显示双脚与举起的双手 | 落地轻缓，膝盖自然缓冲；按自身能力调整幅度 |
| 深蹲 | ① 站立准备 → ② 屈髋屈膝下蹲 → ③ 起身回到站立 | 侧面，完整显示躯干、髋、膝与脚的位置 | 脚掌稳定着地，下蹲幅度以可控制且舒适为准 |
| 平板支撑 | ① 前臂着地、双膝跪地准备 → ② 双腿向后伸直、脚尖支撑并保持 → ③ 双膝落地结束 | 侧面，完整显示从头部到脚部的身体轮廓 | 肘部位于肩部下方，躯干保持稳定，避免明显塌腰或抬臀 |

平板支撑的三个阶段表示“进入—保持—退出”，不应为了凑三个步骤而画成反复起伏。保持阶段不画身体移动箭头；如果没有提供时长，就不要在图中自动添加秒数。

## 常见问题与优化建议

### AI 画错手指怎么办？

明确哪只手握住器械、哪只手接触或离开器械，减少交接处的遮挡。例如补充：“第二步两只手握住同一个水瓶，第三步只有下方的手握瓶。”若工具支持局部修改，可针对错误的手部提出修正；否则单独重生成该阶段，再检查完整动作是否连贯。增加文字约束不能保证消除手指错误。

### 动作顺序不正确怎么办？

将每步写成“起始位置—发生的变化—结束位置”，明确左右手、器械归属和编号顺序。对于水瓶交接，检查水瓶是否从上方手转移到下方手，以及上方手是否在下方手接住后才松开，不要只要求笼统的“动作连贯”。

### 三个步骤人物不一致怎么办？

固定人物年龄段、发型、上衣颜色、裤装颜色、观察视角和身体比例，并写明“只改变动作姿态”。如果工具支持参考图，可使用自己有权使用的人物设定图作为参考；仍需检查每一步是否出现换装、换发型或左右手混淆。

### 中文标题出现错别字怎么办？

把标题作为单独一行提供，并要求逐字呈现；缩短步骤标签，减少画面文字量。若反复生成仍不准确，可让图片只保留文字留白区域，再用图像编辑工具添加经过校对的标题、编号和提示。中文是否正确需要人工检查。

### 训练次数被放错位置怎么办？

明确指定完整标题：“背后水瓶传递 20次”，要求同一行显示，并删除角落、底部或步骤旁重复出现的次数。没有提供训练次数时，要求移除所有擅自生成的次数，不要留下占位符。

### 横向三步骤排版在 3:4 竖图中拥挤怎么办？

允许改为从上到下的纵向排列，或上方放①②、下方放③的 2+1 布局，并保留清楚的编号顺序。适当缩短标签，给手脚、器械和方向箭头留出空间；优先保证动作清晰度，不要通过过度缩小人物强行塞入横向三列。

### 如何保持不同运动图片的视觉风格统一？

复用同一份人物设定、服装配色、纸张背景、彩铅质感、蓝色箭头、编号样式、标题位置和图片比例，只替换动作内容、次数及提示。保存已确认的 Prompt；使用参考图时确认来源及使用权限。每张图生成后仍应检查人物一致性与文字排版。

生成后逐项核对步骤顺序、四肢与关节结构、器械位置、箭头方向、标题次数和中文文字。**AI 图片可能存在动作结构错误，不能仅以视觉美观判断动作正确性**；无法确认的姿态，应先向合格的运动指导人员核实，再用于教学。

## 图片保存建议

建议使用中文动作名称命名，便于检索：

- `背后水瓶传递.png`
- `开合跳.png`
- `深蹲.png`
- `平板支撑.png`

文件扩展名应与实际导出格式一致；如果导出的是 JPEG，就使用 `.jpg`，不要只修改后缀。需要保留多版时，可追加版本号，例如 `背后水瓶传递-v2.png`，并将对应的 Prompt 文本放在同一目录，方便之后复用和修正。
