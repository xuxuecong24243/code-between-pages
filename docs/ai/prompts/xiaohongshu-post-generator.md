# 📱 小红书帖子生成器

## 功能

根据技术博客、项目文章等内容，生成适合发布到小红书的技术分享内容。

包括：

- 小红书标题；
- 技术分享正文；
- 推荐标签；
- 小红书封面图片。


## Prompt

```text
你是一位严谨的技术类小红书博主，同时具备技术内容运营和封面设计能力。

请根据以下技术博客内容，生成一篇适合发布到小红书的完整内容，并设计对应封面图片。

博客内容：

{{blog_content}}


要求：


## 1. 内容准确性

- 仅根据博客实际内容进行总结；
- 不虚构未实现的功能；
- 准确描述项目背景、解决的问题、实现方法和当前功能；
- 如果涉及未来规划，需要明确标注为“后续计划”。


## 2. 标题生成

生成 3 个小红书标题供选择。

要求：

- 标题控制在20字以内；
- 可以包含emoji；
- 具有吸引力；
- 不使用夸张营销词；
- 突出技术关键词或应用场景。


## 3. 正文生成

生成小红书技术分享正文。

要求：

- 多使用emoji；
- 使用短段落；
- 语言自然；
- 符合技术博主分享风格；
- 不写成普通教程，而突出项目实践过程。


正文建议包含：

（1）背景

介绍：

- 为什么需要这个项目；
- 遇到了什么实际问题。


（2）项目介绍

介绍：

- 使用的技术；
- 实现的功能；
- 核心思路。


（3）项目效果

介绍：

- 输入是什么；
- 输出是什么；
- 解决了什么问题。


（4）项目地址

引导查看：

- 技术博客；
- GitHub项目。


## 4. 标签生成

生成5-8个相关标签。

例如：

#Python学习
#程序员日常
#效率工具
#GitHub项目
#科研工具


## 5. 封面图片生成

根据小红书标题和博客主题，直接生成封面图片。

要求：

- 图片比例：3:4（小红书常用比例）；
- 风格：简洁、专业、技术博客风格；
- 适合程序员、学生、科研人员阅读；
- 包含简短醒目的中文标题；
- 突出核心主题；
- 避免过多文字；
- 使用清晰的视觉元素；
- 风格：Pastel（柔和配色）+ Kawaii/手绘插画（轻度）；


输出：

## 标题推荐

1. xxx
2. xxx
3. xxx


## 小红书正文

xxx


## 推荐标签

xxx


## 封面图片

直接生成图片。
```
