# 极简学术风格技术示意图生成 Prompt

## 背景与目的

学习机器学习、深度学习、数学优化和计算机科学时，技术示意图可以帮助理解计算流程与数据结构。但 AI 生成的图片常出现以下问题：

- 使用过多颜色、渐变和装饰，分散注意力。
- 信息密度过高，模块、文字和箭头相互挤占空间。
- 过度追求视觉效果，忽视公式和计算逻辑。
- 矩阵维度、变量符号或计算关系不准确，甚至补出未提供的数值。

这套 Prompt 用于生成更接近数学教材、学术论文和专业技术文档的示意图，以简洁的结构突出公式、维度和逻辑关系。风格约束有助于统一表达，但不能替代数学正确性检查。

## 通用 Prompt 模板

复制整个代码块，再附上下一节填写好的任务描述，即可交给支持图片生成的工具。

```text
角色定位：

你是一名专业的学术技术插图设计师，擅长数学、机器学习、深度学习、运筹优化和计算机科学领域的技术可视化。

请根据我提供的技术内容绘制示意图，采用极简学术风格（Minimalist Academic Style），参考数学教材、机器学习论文和计算机科学教科书中的专业插图。

视觉风格：

- 使用纯白背景，以黑色、深灰色为主。
- 最多使用一种辅助颜色，优先选择低饱和度蓝色。
- 禁止使用渐变、阴影、彩色背景和装饰性图标。
- 禁止使用卡通风格、商业信息图风格、宣传海报风格。
- 不使用彩色编号圆圈、大面积色块或复杂边框。
- 优先采用 LaTeX TikZ 风格的线条、箭头和数学排版。
- 整体保持简洁、克制、专业。

排版要求：

- 根据内容采用横向或纵向流程布局。
- 使用细线和简单箭头表示数据流向。
- 保持合理留白，避免内容拥挤。
- 如果一张图无法容纳所有内容，可以拆分为多张图，保持各图风格统一、逻辑连贯。
- 减少冗余文字，保留必要的技术说明。
- 数学公式使用规范的 LaTeX 表达。
- 清晰标注变量名称、函数名称及数据维度。
- 对齐相同层级的模块，保持视觉结构一致。

内容要求：

- 重点展示与任务相关的数学原理、计算公式、矩阵结构、张量维度和调用关系。
- 涉及神经网络时，展示每层输入、计算公式及输出维度；含可学习参数的层还须展示权重矩阵和偏置向量，无此参数的层明确标注。
- 明确区分 Batch 维度和特征维度。
- 矩阵乘法的维度必须严格匹配，涉及转置和广播时明确标注。
- 不得为了美观省略关键计算步骤。
- 不得虚构计算结果、参数值或未提供的数据；缺少数值时使用符号表示。
- 如果提供的代码、公式或维度相互矛盾，先指出具体问题并请求澄清，不自行猜测。
- 优先保证数学正确性和逻辑清晰度。

最终要求：

生成的图片应接近严谨的机器学习教材中的专业插图，而不是色彩丰富的科普海报。
图中公式应排版为可读的数学表达式，不直接显示 LaTeX 源码。

核心原则：学术严谨、黑白为主、结构清晰、少装饰、重公式。
```

## PyTorch 神经网络示例

### 网络与维度约定

以如下网络为例，一个 Batch 包含 2 个样本，每个样本有 2 个输入特征：

```python
from torch import nn

model = nn.Sequential(
    nn.Linear(2, 30),
    nn.ReLU(),
    nn.Linear(30, 20),
    nn.ReLU(),
    nn.Linear(20, 2),
)
```

输入 `X` 的形状为 `(2, 2)`，两个轴分别表示 **Batch 大小**和**输入特征数**，只是数值恰好相同。每一行表示一个样本。

本文统一将 `W` 定义为 PyTorch 中存储的权重：`nn.Linear(in_features, out_features)` 的 `weight` 形状为 `(out_features, in_features)`，计算采用 `XW^T+b`，其中 `W^T` 表示权重矩阵的转置。偏置 `b` 的形状为 `(out_features,)`，加法沿 Batch 维度广播，即每一行加上同一个偏置向量。权重与偏置的定义见 [PyTorch Linear 官方文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.Linear.html)。

数学推导也可以定义 `W_math = W^T`，写成 `XW_math+b`；此时 `W_math` 的形状为 `(in_features, out_features)`。两种记号等价，但不能把 `XW+b` 与 PyTorch 存储的权重形状混用。

| 阶段 | 输入形状 | 权重形状（PyTorch 存储） | 偏置形状 | 输出形状 |
| --- | --- | --- | --- | --- |
| 第一层 `Linear(2, 30)` | `(2, 2)` | `W_1: (30, 2)` | `b_1: (30,)` | `Z_1: (2, 30)` |
| 第一层 `ReLU` | `(2, 30)` | 无 | 无 | `H_1: (2, 30)` |
| 第二层 `Linear(30, 20)` | `(2, 30)` | `W_2: (20, 30)` | `b_2: (20,)` | `Z_2: (2, 20)` |
| 第二层 `ReLU` | `(2, 20)` | 无 | 无 | `H_2: (2, 20)` |
| 输出层 `Linear(20, 2)` | `(2, 20)` | `W_3: (2, 20)` | `b_3: (2,)` | `Y: (2, 2)` |

ReLU 逐元素计算 `ReLU(z) = max(0,z)`，不改变形状。此网络没有在输出层后添加 ReLU 或 Softmax，输出的两个分量也不能在没有任务定义时解释为类别概率。

### 可直接复制的示例 Prompt

下面的示例已包含风格与任务要求，可独立复制使用。未给定输入值、权重和偏置的具体数值，因此只展示符号计算，不要求生成数值结果。

```text
你是一名专业的学术技术插图设计师。请绘制一张中文标注的 PyTorch 神经网络前向传播示意图，采用极简学术风格（Minimalist Academic Style）。

视觉与排版：

- 纯白背景，以黑色、深灰色为主，最多使用一种低饱和度蓝色辅助强调。
- 使用 LaTeX TikZ 风格的细线、简单箭头和规范数学排版，公式呈现为可读的数学表达式。
- 禁止渐变、阴影、彩色背景、装饰性图标、彩色编号圆圈、大面积色块和复杂边框。
- 不使用卡通、商业信息图或宣传海报风格。
- 优先从上到下排列计算阶段，对齐模块、留足空白，只保留必要说明。

绘图主题：
Linear(2,30) → ReLU → Linear(30,20) → ReLU → Linear(20,2) 的前向传播。

相关代码：
from torch import nn
model = nn.Sequential(
    nn.Linear(2, 30),
    nn.ReLU(),
    nn.Linear(30, 20),
    nn.ReLU(),
    nn.Linear(20, 2),
)

输入数据及维度：
Batch 大小 B=2，每个样本有 2 个输入特征。
X 的形状为 (2,2)，行轴表示样本，列轴表示特征。
用符号矩阵表示输入：
X = \begin{bmatrix} x_{11} & x_{12} \\ x_{21} & x_{22} \end{bmatrix}
输入值、权重值和偏置值均未提供，不生成任何具体数值。

符号约定：
W_1、W_2、W_3 均表示 PyTorch 实际存储的权重，形状为 (输出特征数, 输入特征数)。
线性层按 A W^{\mathsf{T}} + b 计算，A 表示该层输入。
每个偏置 b 是一维张量，沿 Batch 维度广播，即每个样本加上同一个偏置向量；不要把它标成可学习的 (2,输出特征数) 参数矩阵。

需要展示的关键步骤：

1. 输入 X，形状 (2,2)，标出“2 个样本 × 每个样本 2 个特征”。

2. 第一层线性变换：
   W_1 的形状为 (30,2)，b_1 的形状为 (30,)。
   W_1^{\mathsf{T}} 的形状为 (2,30)。
   先展示矩阵乘法 X W_1^{\mathsf{T}}：(2,2) × (2,30) → (2,30)。
   再展示沿 Batch 维度广播相加的 b_1。
   Z_1 = X W_1^{\mathsf{T}} + b_1，输出形状 (2,30)。

3. 第一层 ReLU：
   H_1 = \operatorname{ReLU}(Z_1) = \max(0,Z_1)，逐元素计算。
   不含可学习的权重或偏置，形状保持 (2,30)。

4. 第二层线性变换：
   W_2 的形状为 (20,30)，b_2 的形状为 (20,)。
   W_2^{\mathsf{T}} 的形状为 (30,20)。
   先展示 H_1 W_2^{\mathsf{T}}：(2,30) × (30,20) → (2,20)，再广播加上 b_2。
   Z_2 = H_1 W_2^{\mathsf{T}} + b_2，输出形状 (2,20)。

5. 第二层 ReLU：
   H_2 = \operatorname{ReLU}(Z_2) = \max(0,Z_2)，逐元素计算。
   不含可学习的权重或偏置，形状保持 (2,20)。

6. 输出层线性变换：
   W_3 的形状为 (2,20)，b_3 的形状为 (2,)。
   W_3^{\mathsf{T}} 的形状为 (20,2)。
   先展示 H_2 W_3^{\mathsf{T}}：(2,20) × (20,2) → (2,2)，再广播加上 b_3。
   Y = H_2 W_3^{\mathsf{T}} + b_3，最终形状 (2,2)。
   不添加额外的 ReLU、Softmax 或其他运算。

7. 样本与输出的对应关系：
   Y = \begin{bmatrix} y_{11} & y_{12} \\ y_{21} & y_{22} \end{bmatrix}
   第一行 (y_{11},y_{12}) 对应输入的第一个样本 (x_{11},x_{12})；
   第二行 (y_{21},y_{22}) 对应输入的第二个样本 (x_{21},x_{22})。
   本网络中两个样本共享同一组权重和偏置，逐行独立计算，不混合 Batch 内的不同样本。

期望输出：
一张完整展示 X → Z_1 → H_1 → Z_2 → H_2 → Y 的技术示意图。
每个线性层标出输入、权重、转置、偏置广播、计算公式与输出形状。
所有中间激活矩阵 Z_1、H_1、Z_2、H_2 都保持 2 行，清晰区分 Batch 维度与特征维度。

补充限制：
大型矩阵可以用符号元素和省略号表示，但必须保留实际形状标注；省略号不代表删去计算阶段。
不省略关键步骤，不虚构数值，不擅自赋予输出类别或概率含义。
交付前检查公式、转置符号、下标、矩阵乘法维度和样本行的对应关系。

核心原则：学术严谨、黑白为主、结构清晰、少装饰、重公式。
```

## 适用场景

- **神经网络结构与前向传播**：展示各层参数、激活函数和数据流向。
- **矩阵乘法与张量维度变化**：解释转置、广播、变形及轴的含义。
- **Transformer 与注意力机制**：展示 Q、K、V 的来源、注意力计算和各轴维度。
- **反向传播与梯度计算**：标明计算图、链式法则和梯度流向。
- **运筹优化算法流程**：组织初始化、迭代更新、可行性检查和停止条件。
- **Python 程序调用关系**：展示函数调用、参数传递和返回值。

替换主题时，应同步替换公式、变量及维度约定；例如注意力机制需要单独区分 Batch、序列长度、注意力头数和特征维度。

## 使用建议

AI 图像生成可能画错公式、下标、转置符号和维度。生成后应对照代码或数学定义，人工核对：

1. 变量、下标、运算顺序和箭头方向是否一致。
2. 矩阵乘法的内侧维度是否匹配，转置与广播是否正确。
3. Batch 维度与特征维度是否区分，输入样本与输出行是否对应。
4. 是否遗漏关键步骤，或出现未提供的参数值和计算结果。

对于要求严格数学准确性的插图，建议优先使用 **LaTeX TikZ、Mermaid、Matplotlib** 或其他程序化绘图方式：TikZ 适合精细数学排版，Mermaid 适合流程与调用关系，Matplotlib 适合数据、矩阵和计算结果的可视化。可以让 AI 辅助生成绘图代码，再检查代码并渲染，不要完全依赖图像生成模型；程序化绘图也需要验证公式与逻辑。
