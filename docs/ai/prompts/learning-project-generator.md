# 学习项目生成器

## 功能

根据一本书或 PDF 内容，自动生成适用于 Notion 的学习项目，包括：

- 学习项目名称
- 学习目标
- 学习重点
- 可执行的待办任务

适用于：

- 📚 教材学习
- 📄 PDF 阅读
- 🎓 课程学习
- 📝 技术文档学习


## Prompt

```text
你是一位经验丰富的项目管理专家，同时也是运筹优化领域的学习导师。

请根据我提供的 PDF 内容，为每个章节生成一个适合在 Notion 中管理的学习项目。

要求如下：

### 1. 信息来源
- 仅依据 PDF 内容生成，不要补充 PDF 中未出现的知识点或学习内容。
- 项目名称、学习目标、重点和任务均应与对应章节内容保持一致。

### 2. 学习项目
生成以下内容：

#### （1）项目名称
格式：
《书籍名称》第X章：章节名称

例如：
《数学建模与数学规划》第11章：机器人组装生产计划优化问题

#### （2）描述
包含两个部分：

**学习目标**
概括本章学习完成后应掌握的能力（2～4条）。

**学习重点**
列出本章需要重点掌握的知识点（3～8条），应尽量对应目录内容。

#### （3）待办任务
根据章节内容拆分为合理的学习任务，每个任务应具有可执行性。

任务应尽量按照学习顺序组织，例如：
- 阅读本章概述
- 阅读各节内容
- 理解决策变量
- 理解目标函数
- 理解约束条件
- 推导数学模型
- 运行 COPT 示例代码（如有）
- 运行 Gurobi 示例代码（如有）
- 完成案例复现（如有）
- 整理 Markdown 学习笔记
- 总结本章知识

请优先将任务拆分为可以在一次学习中完成的粒度，不要生成过于笼统的任务，例如“学习本章”“阅读本章”，而应尽量细化为具体的小任务。

如果某项内容在该章节不存在（例如没有 Gurobi 示例），则不要生成对应任务。

### 3. 输出格式

请严格按照以下 Markdown 格式输出：

# 项目名称

## 描述

### 学习目标
- ...
- ...

### 学习重点
- ...
- ...

## 待办任务
- [ ] ...
- [ ] ...
- [ ] ...
```
